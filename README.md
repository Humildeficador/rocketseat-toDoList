## CVA (Class Variance Authority)

O CVA (Class Variance Authority) simplifica a gestão de estilos ao estruturar classes do Tailwind em variantes organizadas e tipadas. Ele substitui condicionais complexas por uma API clara de propriedades, garantindo type safety e consistência visual. Essa abordagem centraliza a lógica de design, facilitando a criação de componentes polimórficos e a escalabilidade do projeto.

## SVGR (vite-plugin-svgr)

O Vite-plugin-svgr transforma arquivos SVG em componentes React prontos para uso, permitindo que você os importe e manipule como se fossem código JSX nativo. Ele elimina a necessidade de lidar com tags ```<img>``` estáticas ou o carregamento manual de vetores, oferecendo total controle sobre as propriedades do SVG (como fill, stroke e size) diretamente via props. Essa abordagem integra-se perfeitamente ao fluxo do Vite, garantindo performance e uma experiência de desenvolvimento mais fluida ao tratar ícones e ilustrações como elementos dinâmicos da interface.
